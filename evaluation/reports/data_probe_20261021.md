# 데이터 출처 점검 (2026-10-21, 2~4월 전체 뉴스 수집 직전)

> 작성일: 2026-10-21

> 경고: 사용 불가로 **새로 바뀐** 출처는 없다. GDELT 기사 검색 API 는 이전처럼 계속 사용 불가(429)이고, GKG 원본 파일로 대체한다.

점검 스크립트는 프로젝트 밖 임시 폴더에서 `.venv/Scripts/python` 으로 실행했다. 출처마다 1~2건만 요청했고, GDELT 는 요청 사이 5초, 네이버·RSS 는 1초 넘게 간격을 두었다.

## 전체 뉴스 수집 관련 참고

- 세 시점 HEAD 크기 평균은 일반 + translation 합쳐 15분당 약 9.6MB. 2/1~4/30(89일 × 96배치)이면 약 82GB로, 계획한 약 94GB(15분당 약 11MB 기준) 안쪽이다. 원본은 메모리에서만 거르고 저장하지 않으므로 디스크 부담은 작다(C: 여유 약 849GB).
- 2~4월 중 앞·중간·끝 시점의 파일이 모두 응답했다. 다만 15분 단위 파일 중 일부가 빠져 있을(404) 수 있으며, 수집 코드는 404 를 빈 결과로 처리한다.
